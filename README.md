A vintage travel poster for a place that does not exist: SOLMARA, an island
lagoon under a dusk sky that never fully darkens, lit by two suns — one large
and gold, one small and orange. Its landmark is a faceted crystal spire on a
small island in the middle of the lagoon, its tip glowing, reflected in calm
turquoise water. The invented place name is set large and legible at the top,
with one short descriptor line beneath it. No quotes, no star ratings, no
other copy.

## Run it

Requires Python 3.13 and Pillow; no network access, no external assets.

```bash
python3 main.py
```

The program draws the poster entirely in code and writes
`/output/entry.png` (PNG, 1024×1024, under 1 MiB), deterministically.
